对内：从「人拼工具」到「Agent 接力」

过去主要靠人把各平台工具组合做 CADD。Ailux 把这条操作经验按项目记下来，下一轮直接接着用，减少重复搭建、缩短上手周期。

对外：自有抗体模型是核心差别

外部 Agent 多用公开模型与公开工具。Ailux 的差别在于自有抗体模型——模型强，是因为背后有私有数据和已跑通的项目流程。

生态构建：在本人权限下，Agent 通过 Ailux 自研算法和 Nexus 调用底层算法，使用项目数据池和公司算力，并按权限接上飞书文档。
02专项测试 · 示例包

只测短流程和单模型，不测完整亲和力

全面覆盖对比现阶段意义不大。通用 Agent 铺得开，很多任务成功率并不高，看起来完整，专家一看就知道走不下去。本次只在抗体专项里选短任务比。完整亲和力流程运行时间过长，不纳入测试。
测试项从 Ailux Agent 试用示例包 里选。同一提示词、同一示例文件、同一验收标准。结果跑完再填，页上不预写分数。
