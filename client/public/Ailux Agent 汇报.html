工程与集群资源

算力从哪来

本人权限下的公司集群

Agent 通过 Ailux 自研算法和 Nexus 调用底层算法，使用项目数据池和公司算力，把计算提交到公司 Slurm 集群。

每条作业带资源记录

集群名称、CPU、GPU、内存、起止时间、排队 / 运行 / 完成 / 失败，以及调度日志。失败作业保留日志，便于回看。
